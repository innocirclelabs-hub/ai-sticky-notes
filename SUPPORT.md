# Support, Feedback and Feature Requests

AI Sticky Notes welcomes practical feedback from early-access users.

## Where to post

- **Something broke:** Open **GitHub Issues → Bug report**.
- **Something should work differently:** Open **GitHub Issues → Feature request**.
- **Need help installing:** Open **GitHub Issues → Installation help**.
- **Security concern:** Follow [Private security reporting](.github/SECURITY.md) — don't post exploitable details publicly.

GitHub Issues are the bug, feature, and setup tracker. The Windows colleague-test ZIP is published in Releases. Use its own Setup and checklist, and report the first failing stage. Discussions are not required.

## Useful bug reports

Include the product version, operating system, Chrome version, whether you're in browser-local or connected MCP mode, what you did, what you expected, what actually happened, and the exact non-sensitive error message. A **redacted** screenshot is helpful.

Please **remove** private conversations, note contents, account identifiers, login cookies, service URLs/tokens, screenshots of other ChatGPT tabs, or financial/private data. Do not paste secret-bearing logs.

## Feature suggestions

Tell us the problem, your expected workflow, a concrete example, and whether it affects task planning, approval, completion tracking, guardrails, session/project separation, language, window controls or installation.

Feature requests do not create an obligation to implement or release anything; status updates will be tracked in Issues.

## Updates and known limitations

Watch the repository's **Releases** tab. GitHub unpacked Chrome extensions do **not** update themselves; check [INSTALL.md](INSTALL.md).

**Current focus:** ChatGPT web desktop Chrome. **Planned later:** Codex. Other browsers and mobile platforms are not presently advertised as supported.

**Known testing-release limitations:** The standalone browser-local interface cannot make the ChatGPT model read or update notes automatically. Full synchronization needs an authorized MCP connection and appropriate ChatGPT permissions. Do not equate the isolated use-case screenshots with verified public live-chat installation.
