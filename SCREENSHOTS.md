# Screenshot Provenance

This repository contains eleven screenshots captured from actual browser-rendered product demonstrations using isolated sessions and sample data.

- `student-01` through `student-04`: blank workspace, whole-plan review, progress, and completion.
- `student-05`: the rendered fictional assignment output.
- `web-01` through `web-04`: the corresponding website workflow.
- `web-05` and `web-06`: the fictional club website at desktop and mobile sizes.

A deterministic local driver supplied tool results and completion evidence in these examples. They are **not screenshots of autonomous model execution in a real logged-in ChatGPT conversation**. The examples disclose no personal ChatGPT conversation or customer notes. Source test runners and sample HTML are not included.

The images demonstrate the core tasks-and-rules workflow. Newer group management and accordion controls are described in the current development notes; these sample captures are not represented as screenshots of every latest-build feature.
